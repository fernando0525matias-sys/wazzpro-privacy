1. Introducción

WazzPro Sender es una aplicación de mensajería SMS para Android. Permite consultar conversaciones, redactar, enviar y recibir SMS en el dispositivo. Puede configurarse como aplicación SMS predeterminada. De forma opcional, incluye herramientas para preparar mensajes personalizados a partir de una lista que el usuario importa (archivo Excel) y para seguir el resultado de esos envíos.

WazzPro no tiene un servidor propio para procesar campañas, Excel, variables, conversaciones ni resultados. Esos datos se procesan localmente en el dispositivo.

Cuando usted envía un SMS, el mensaje sí sale del teléfono por la red del operador móvil de la SIM utilizada. Eso es el funcionamiento inherente del SMS, no un envío a un servidor de WazzPro. Esta política no afirma que los SMS nunca salgan del dispositivo.

4. Cómo utiliza los datos

Los datos se usan únicamente para las funciones de la aplicación: conversaciones SMS; redactar, enviar y recibir; personalizar un mensaje con variables de una lista importada (en el dispositivo); mostrar resultados; notificaciones locales; recuperación de una campaña interrumpida según usted decida; y generar un CSV si lo solicita.

  • Pendiente: el mensaje aún no se envió o está en cola.
  • Enviado: Android aceptó el envío (SENT). No significa que el destinatario lo haya recibido.
  • Entregado: solo si existe una confirmación real de entrega (DELIVERED). WazzPro no afirma entrega al destinatario cuando solamente existe SENT.
  • Fallido: el envío no se completó.
  • Sin confirmar: el estado no está confirmado (UNKNOWN). No se presenta como entrega.

No está integrado AdMob. No hay Firebase, analytics de producto ni SDK publicitario en esta versión.

5. SMS y mensajes

WazzPro puede actuar como aplicación SMS predeterminada (ROLE_SMS). Usted lo confirma en el selector de Android; la app no se autoasigna el rol al abrir.

Los SMS enviados salen mediante el operador móvil del usuario, a través de Android SmsManager. La recepción usa SMS_DELIVER (no se declara RECEIVE_SMS) y se guarda en Room. El inbox lee Room; no consulta content://sms para armar la bandeja.

6. Campañas y Excel

De forma opcional puede importar una lista propia en Excel (.XLSX). El archivo se lee en memoria en este dispositivo; las celdas se copian a la base local; las variables se sustituyen localmente; usted previsualiza y, si lo decide, inicia el envío.

WazzPro no tiene servidor propio para procesar las campañas. Las campañas son herramientas adicionales para trabajar con listas propias.

7. Almacenamiento local (Room)

La base Room (sms-manager.db) actualmente no está cifrada. También hay preferencias locales y, si exporta, un CSV temporal en la caché. No se afirma cifrado en reposo.

8. Transmisión al operador

No existe backend propio ni sincronización en la nube de WazzPro. No hay permiso de producto INTERNET. Cuando envía un SMS, el número y el cuerpo salen del dispositivo hacia la red del operador. Si el operador no confirma entrega, el estado permanece Enviado (SENT), no Entregado.

9. CSV

El CSV se genera localmente cuando el usuario lo solicita. No se comparte automáticamente. Usted decide si lo comparte o exporta mediante el selector de Android.

Campos: ID de campaña, ID de mensaje, teléfono, nombre, transporte, estado, fechas de creación/envío/entrega, intentos, código y texto de error. El CSV no incluye el cuerpo del SMS, el Excel, DNI, saldo, días de mora ni el mapa completo de variables.

10. MMS

El soporte MMS es parcial / placeholder. Puede registrarse el aviso «Mensaje multimedia (MMS)». No interpreta el PDU, no muestra imágenes ni adjuntos y no envía MMS. No debe describirse como funcionalidad completa.

11. Permisos

SEND_SMS, READ_SMS, RECEIVE_MMS, RECEIVE_WAP_PUSH, READ_PHONE_STATE, POST_NOTIFICATIONS, servicios en primer plano / WAKE_LOCK y RECEIVE_BOOT_COMPLETED, con los usos descritos en el manifiesto de producto. RECEIVE_SMS no está declarado. INTERNET no está declarado. READ_CONTACTS no está declarado.

12. Servicios de terceros

En la versión actual no hay Firebase, AdMob, analytics, crash reporting de producto, trackers, WebView de producto ni backend de WazzPro.

13. Publicidad

14. Conservación

No existe un borrado automático por tiempo. Puede borrar una campaña, una plantilla, o desinstalar / borrar los datos de la aplicación. No hay borrado de hilo de conversación en la interfaz ni portal remoto de borrado.

15. Seguridad

Los datos viven en el dispositivo, sin backend WazzPro. Room no está cifrada. allowBackup está desactivado. No se afirma seguridad absoluta del teléfono.

16. Copias de seguridad

WazzPro intenta no incluir la base, las preferencias ni los cuerpos SMS en la copia de seguridad en la nube de Google configurada por las reglas de la app. Eso no es una protección absoluta frente a un dispositivo desbloqueado, ADB o capturas.
